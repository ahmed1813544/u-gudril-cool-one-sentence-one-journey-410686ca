## What it does

`main.py` writes one complete story about a journey, told in exactly one
sentence, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

The story follows Mara from a dawn departure with her grandfather's brass
compass, across three borders on a bus that smells of diesel and oranges,
to the sea — where the journey turns: she buries the compass and walks home
by the stars instead.

## Run it

```sh
python3 main.py
```

The program is deterministic (the same sentence, byte-identical, on every
run), uses only the Python standard library, and makes no network calls and
reads no files outside the repository.
